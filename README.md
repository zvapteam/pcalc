# Калькулятор смет

Фронтенд калькулятора смет для страницы на Tilda. Данные хранятся в Google Таблицах через Apps Script (Code.gs).

- `calc.js` — логика и интерфейс
- `calc.css` — оформление
- `Code.gs` — бэкенд для Google Apps Script (копия; рабочая версия живёт в редакторе Apps Script)

Подключение на Tilda — один блок T123 (см. `tilda-block.html`).

Каждая выпущенная версия — отдельная ветка `release-X.Y` (например, `release-4.7`), которая после выпуска не меняется.
Блок на Tilda загружает файлы через jsDelivr: `https://cdn.jsdelivr.net/gh/zvapteam/pcalc@release-4.7/calc.js`.
Обновление — сменить `VERSION` в блоке на новый номер; откат — вернуть прежний.

Ключ доступа и адрес скрипта в репозиторий не кладутся — они задаются только в блоке на Tilda.
