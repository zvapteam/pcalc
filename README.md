# Калькулятор смет

Фронтенд калькулятора смет для страницы на Tilda. Данные хранятся в Google Таблицах через Apps Script (Code.gs).

- `calc.js` — логика и интерфейс
- `calc.css` — оформление
- `Code.gs` — бэкенд для Google Apps Script (копия; рабочая версия живёт в редакторе Apps Script)

Подключение на Tilda — один блок T123 (см. `tilda-block.html`). Версия выбирается тегом в ссылке jsDelivr:
`https://cdn.jsdelivr.net/gh/<владелец>/<репозиторий>@<версия>/calc.js`

Ключ доступа и адрес скрипта в репозиторий не кладутся — они задаются только в блоке на Tilda.
